IQ-TREE Command-line=iqtree3 -B 1000


NOTE:
1. Just change the part after "=".
2. The input alignment (-s XXXX) and the number of threads (-T) will be specified automatically by EasyCGTree.


IQ-TREE Command-line examples:

1. Infer maximum-likelihood tree from a sequence alignment with the best-fit model automatically selected by ModelFinder:
     iqtree3

2. Ultrafast bootstrap (1000 replicates):
     iqtree3 -B 1000

3. Combine ModelFinder, tree search, ultrafast bootstrap and SH-aLRT test:
     iqtree3 --alrt 1000 -B 1000

4. Use a given model instead of ModelFinder:
     iqtree3 -m LG+G4 -B 1000

5. For more options, please visit https://iqtree.github.io/ or run "bin/iqtree3 -h".



===========================================================

FastTree Command-line=FastTreeMP

NOTE:
1. FastTree is very fast and simple to use. An example with more options: FastTreeMP -gamma
2. For more options, please visit https://morgannprice.github.io/fasttree/ or run "bin/FastTreeMP -expert".


===========================================================

astral Command-line=astral-weighted -S -x 100

NOTE:
1. astral-weighted is wASTRAL of ASTER (https://github.com/chaoszhang/ASTER). '-S -x 100' sets how the branch
   support values of the gene trees are used as weights (see "bin/astral-weighted -h").
2. The input gene trees (-i), the output file (-o) and the number of threads (-t) are specified automatically.


************** Reminder ******************

If users are very familiar with the three applications, it is a better choice to use them (./bin/) directly
since all input data prepared by EasyCGTree are available.
